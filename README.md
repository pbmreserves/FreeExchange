# Free Exchange

Scan-to-exchange crypto swap service.

## Product principles
- No wallet connection or wallet authorization.
- Users enter a destination address and pay by scanning a QR code with their own wallet.
- Orders are settled from on-chain payment detection.
- Fixed-rate and floating-rate exchange modes.
- No user asset balance/custody account in the application.

## Initial scope
BTC, ETH, USDT and USDC, with network treated as a first-class field.

> This repository is independent from PBMReserves.
